## 概念笔记

### 1. 线性组合与张成

给定向量集 {x₁, …, xₖ}，任何形如 Σ λᵢxᵢ（λᵢ ∈ ℝ）的向量称为其**线性组合**；所有线性组合构成的集合称为该向量集的**张成（span）**。张成是包含原向量集的最小子空间——它是「这些向量能够得着的世界」的精确边界。

### 2. 线性无关的两种刻画

向量集 {x₁, …, xₖ} **线性无关**，有两种等价表述：

- **平凡解唯一**：Σ λᵢxᵢ = 0 仅当 λ₁ = … = λₖ = 0 成立；
- **无冗余**：任何一个向量都无法表示为其余向量的线性组合。

两种刻画的等价性值得咀嚼：前者是代数判据（可直接用于演算），后者是结构性陈述（揭示冗余的存在）。若某个向量可被其余向量表出，则该向量对张成毫无贡献——它是「信息上的零向量」。

### 3. 判定方法：高斯消元

将向量并置为矩阵 A = [x₁ | … | xₖ]，求解齐次系统 Aλ = 0。施以初等行变换至**行阶梯形**：若每一列均含主元（pivot），则仅有平凡解，向量集线性无关；存在无主元的列 ⇔ 存在非平凡解 ⇔ 线性相关。主元列恰对应原向量集的一个极大线性无关子集。

### 4. 与 DL 的连接

线性无关直接回答「特征里有没有水分」：特征矩阵列线性相关意味着特征间存在确定性冗余，秩亏损会导致最小二乘解不唯一、协方差矩阵不可逆——这在后面的正规方程与主成分分析中会反复索债。

## 推导与例子

- x₁ = (1, 2), x₂ = (2, 4)：x₂ = 2x₁，相关——张成只是一条直线。
- x₁ = (1, 0), x₂ = (1, 1)：设 λ₁x₁ + λ₂x₂ = 0，得 λ₁ + λ₂ = 0 且 λ₂ = 0，故 λ₁ = λ₂ = 0，无关。

## 心态历程

> 「线性无关」这个词本科就听过无数遍，但今天第一次觉得它不只是定义背熟了就算懂。两种刻画的等价性自己推了一遍：从「无非平凡解」推出「无冗余」要做一次反设，推通那一步有种齿轮咬合的手感。高斯消元判无关的部分和 2.3 串起来了，消元不再是算术杂务，而是在读取矩阵的结构信息。照例用两个二维小例子手验，二维的好处是画出来就知道答案对不对，骗不了人。
