## LC 3 无重复字符的最长子串（Longest Substring Without Repeating Characters）

### 手稿代码

```python
def lengthOfLongestSubstring(self, s: str) -> int:
    seen = set()
    i = 0
    ans = 0
    for j in range(len(s)):
        while s[j] in seen:
            seen.remove(s[i])
            i += 1
        seen.add(s[j])
        ans = max(ans, j - i + 1)
    return ans
```

### 解析

这是滑动窗口（双指针）的标准应用：右指针 `j` 不断扩张窗口，一旦发现 `s[j]` 与窗口内字符重复，左指针 `i` 就逐个收缩，直到窗口内无重复为止。`seen` 集合始终维护当前窗口 `[i, j]` 内的字符，每次扩张后更新最大长度。

关键在于：左指针只右移不回退，每个字符最多被两个指针各访问一次，因此整体是线性的。

- 时间复杂度：O(n)；空间复杂度：O(Σ)，Σ 为字符集大小
