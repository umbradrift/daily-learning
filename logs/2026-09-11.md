## AI 系统五层架构

从底到顶：

1. **算力层**：GPU/TPU，神经网络训练本质是海量并行矩阵运算
2. **数据层**：采集 → 清洗 → 标注 → 存储，实际工作量常占 60% 以上
3. **框架层**：PyTorch（主流）、TensorFlow，封装矩阵运算与自动求导
4. **模型层**：模型 = 可调参数的大函数；训练 = 调参数，推理 = 参数固定只算输出
5. **应用层**：模型外围的工程（对话界面、RAG、排序服务等）

数据流两条线：
- 训练（离线）：数据 → 前向 → 算损失 → 反向传播 → 更新参数 → 循环
- 推理（在线）：输入 → 前向一次 → 输出

## 神经网络基础

- **神经元**：`输出 = 激活函数(Σ wᵢxᵢ + b)`，加权求和 + 非线性激活；参数就是 w 和 b
- **分层堆叠**：输入层 → 隐藏层（"深度"指层数）→ 输出层；层叠让特征逐层抽象（边缘 → 部件 → 整体）
- **训练三步循环**：前向传播 → 损失函数衡量误差 → 反向传播算每个参数的梯度 + 梯度下降更新
- 类比：梯度下降 = 蒙眼下山，每步朝最陡下坡方向挪一小步

## 经典模型架构（架构差异 = 对数据结构的假设不同）

- **MLP**：全连接，无结构假设，适合表格数据
- **CNN**：卷积核滑动扫描 + 参数共享 → 参数量骤降、位置无关，适合图像（AlexNet 2012、ResNet 残差连接）
- **RNN/LSTM**：循环 + 隐藏状态实现"记忆"，适合序列；已被 Transformer 基本取代，了解思想即可
- **Transformer（2017）**：自注意力让每个词并行地"看"所有词，统一了现代架构（GPT/BERT/ViT/Sora 均基于它）

## Transformer 内部机制（重点）

1. **Embedding**：词 → 向量，语义相近则几何距离近
2. **自注意力 Q/K/V**：每个词生成查询(Q)、键(K)、值(V) 三个向量；Q·K 算相关度 → softmax 归一化成权重 → 对 V 加权求和，得到融合上下文的新表示
   - 公式：`softmax(QKᵀ/√dₖ)V`
   - 例：处理"追"时，注意力自动给主语"猫"、宾语"狗"高权重
3. **多头注意力**：多个头并行，各学一种关注模式（语法/位置/语义），最后拼接
4. **位置编码**：自注意力本身不感知顺序，需 词向量 + 位置向量 注入位置信息
5. **Block 结构**：多头注意力 → 残差+层归一化 → 前馈 MLP → 残差+层归一化；GPT-3 堆了 96 层
   - 注意力负责词间信息交换，MLP 负责逐位置深度加工，残差保证深层可训练
6. **编码器 vs 解码器**：BERT 双向看全文（理解）；GPT 只看左侧（生成，防止偷看答案）
