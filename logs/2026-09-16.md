## Block 四大部件与数学原理

> 今日在另一处逐符号推导了这部分的数学原理：**涉及线代的（投影、拼接、矩阵形状）都能看懂并深入理解；涉及概率论的（均值方差、采样）看着勉强**——详见文末自评。

**符号约定**：n = 序列词数，d = 词向量维度（512），h = 头数（8），d_k = d/h = 64，x = Block 里流动的 (n, d) 矩阵。

### 1. MHA：单头注意力的"多子空间并行版"

$$\text{MultiHead}(X) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) \, W_o$$

$$\text{head}_i = \text{Attention}(X W_i^Q, \; X W_i^K, \; X W_i^V)$$

- `W_i^Q, W_i^K, W_i^V`：第 i 个头的投影矩阵，形状 (d, d_k) = (512, 64)——和单头的 W_q 是同一种东西，只是投影到 64 维小子空间
- `head_i`：第 i 个头在自己的 64 维子空间里跑一遍注意力四步（缩放因子用 √64，跟着点积实际维度走），输出 (n, 64)
- `Concat`：h 个 (n, 64) 沿维度拼回 (n, 512)
- `W_o`：(512, 512) 输出投影，让各头发现的不同模式（指代/位置/语义）真正融合——Concat 只是并排，W_o 才是混合
- 与旧知识的关系：**单头注意力 = h=1 且 W_o=单位矩阵的特例**，没有任何新数学

### 2. 残差连接：x + sublayer(x)

$$x \leftarrow x + \text{MultiHead}(x)$$

- 信息层面：注意力输出降格为"增量修改意见"，原始信息原样保留
- 梯度层面：∂(x+f(x))/∂x = **1** + ∂f/∂x——那个 "1" 是梯度直通车道，没有它 96 层连乘梯度早衰减到 0

### 3. LayerNorm：词内向量的标准化

$$\text{LayerNorm}(x) = \gamma \odot \frac{x - \mu}{\sigma} + \beta$$

- x：某一个词的 512 维向量（每个词**单独**归一化，词间互不干扰）
- μ、σ：这 512 个数自己的均值和标准差（标量）
- γ、β：**可学习**的 512 维向量，逐元素缩放（⊙）和平移——把标准化"一刀切"丢掉的尺度学回来
- 与旧知识的关系：√d 缩放防**点积**膨胀，LayerNorm 防**层间累加**膨胀——同一个"控尺度"思想用在两个位置

### 4. FFN：每个词独立过一个小型 MLP

$$\text{FFN}(x) = W_2 \cdot \text{ReLU}(W_1 x + b_1) + b_2$$

- W₁：(512, 2048)，升维 4 倍——高维空间里纠缠的特征更容易被切开（SVM 核技巧同一直觉）
- ReLU：max(0,·)，提供非线性
- W₂：(2048, 512)，压回原维度
- 与注意力的分工：**MHA 是通信层（跨位置交换信息），FFN 是计算层（位置内独立消化）**；FFN 占全模型约 2/3 参数，有研究认为事实知识主要存在这里

### 四者关系

不是并列零件，是"两种角色 + 两个后勤"：MHA（通信）→ 残差+LN（保障）→ FFN（加工）→ 残差+LN（保障），且**形状守恒**——每步进出都是 (n, d)：MHA 靠 Concat+W_o 保持，FFN 靠 W₂ 压回保持，残差要求同形才能相加。这是设计出来的接口标准，Block 因此能像乐高一样无限堆叠。

## 疑问与 AI 解答

**Q1**：一个层长什么样？是 MHA + FFN 吗？各接一个层归一化和残差？两个子层就是 MHA 和前馈网络？先 MHA 后 FFN？输出作为下一层输入？

**A1**：全对。一个 Block = 两个子层（MHA 子层 + FFN 子层，先 MHA 后 FFN），每个子层各自配一套残差 + LayerNorm，所以一层有两个 LN、两个残差。现代模型多用 pre-norm（LN 放子层前面），原版论文是 post-norm。`(n, d)` 形状守恒让上一层的输出原封不动成为下一层的输入。

**Q2**：每一层的 W_q/k/v 都一样吗？

**A2**：**不一样**——每层有独立的一整套参数（W_q/k/v、W_o、W₁、W₂、γ、β 全部独立），96 层 = 96 套，这是参数量达千亿级的原因。直觉：浅层学局部语法，深层学抽象语义，分工不同所以参数不能共享。

**Q3**：LayerNorm 的 γ、β 是逐维度定制化的，定制化就要绑定位置并协同进化——所以每个 LN 绑定它前面的 MHA/FFN 协同训练，对吗？

**A3**：对。γ、β 是逐维度的可学习向量，每个 LN 实例有独立的一对，绑死在网络的固定位置上，和整个网络一起被反向传播训练。它只服务于那个位置的数值分布。

**Q4（自问自推）**：预测下一个词的环节在 x 跑完所有层之后？再经处理获得新词，新词和 KV cache 作为输入喂回网络，不断循环就是 App 上流式加载的原因？这就是自回归——"自己回归到网络前面再跑一次"？

**A4**：推测全部正确，补上最后拼图：x 跑完所有层 → 最终 LayerNorm → **LM Head**（一个 (d, 词表大小) 的线性层，本质是又一次矩阵乘法）→ 词表上每个词一个分数（logits）→ softmax → 采样 → 新词 → 追加进输入与 KV 缓存 → 再跑一遍。"跑一次一个字"正是自回归的本义；App 上的逐字蹦出不是特效，是 decode 循环的真实速度。

**术语澄清**：两个"解码"别混——① **decoder-only 架构**：GPT 这类模型的整体结构（带因果掩码的 Block 堆叠）；② **decode 阶段**：推理时逐词生成的循环（相对 prefill）。Q4 说的是后者中的 LM Head + 采样环节。
